# Sleepwalk cover
Source: Assets/Dreamer/Cover in the local Unity Dreamer project, read 2026-11-05.
Original Cover figure.png and Sleepwalk title.png are embedded unchanged in sleepwalk-cover-v2.svg.
The SVG reconstructs the cover layout from DreamerCover.Build, AlignTitle and Add (1920x1080 canvas, 55/45-degree menu plane). It is a code-rendered cover adaptation, not a captured Unity screenshot. The menu font uses Eras Light ITC with Segoe UI/Arial fallback. No Unity project files were edited.
